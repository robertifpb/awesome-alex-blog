Creating a clean dark mode with CSS variables

Dark mode looked like a small visual detail at first, but CSS variables made it feel like a real design system decision instead of a quick visual hack.

I wanted a theme switch that would affect the whole site without repeating the same colors in dozens of selectors. CSS custom properties were the easiest way to centralize those choices and make the interface easier to tune.

Instead of hard-coding colors on every component, I defined values like background, text, border, and links at the root level. Then I created another set for the dark theme using the data-theme attribute. That gave me a simple way to swap the full palette in one place.

What worked well

  • Using named variables made the intent of each color clearer.
  • Components automatically adapted when the theme changed.
  • It became easier to keep contrast consistent across cards, buttons, and text.

What I want to improve next

I still want to refine a few combinations to make hover states feel even more balanced in both themes. The main lesson, though, is that theme support becomes much simpler when the design tokens exist from the start.

For a small blog, this approach already feels scalable. If I add more pages later, I can reuse the same variables without redesigning each section from zero.
